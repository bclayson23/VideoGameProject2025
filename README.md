final game project for video game programming class

**Conecpt For Game**

## The Escape: My Encounter with John Pork

### Story
You play as a lost person in a maze. You must find the exit before John Pork finds you!

### Mechanics
You will navigate through the maze while avoiding John Pork to get to the exit.

If he catches you, you will get a jump scare!

### Asthetics
It will be a creepy and unnerving maze.

It will be very dirty.

### Outcomes
If you reach the maze, you win.

If John Pork catches you, you die!


###How To Play!
Use the arrow keys to navigate the maze! You must find the exit! Dont let JP catch you!
